Tutorial Rekomendasi
1
Cari Item di Roblox Catalog
Buka Roblox Catalog, cari aksesoris yang ingin kamu rekomendasikan. Salin Asset ID dari URL (angka setelah /catalog/). Contoh: roblox.com/catalog/1234567890 → Asset ID = 1234567890.
2
Salin Link Preview Gambar
Drag gambar preview aksesoris dari halaman Roblox langsung ke tab URL browser (tab tempat kamu mengetik alamat website). Setelah gambar terbuka di tab baru, copy link di address bar (biasanya berformat https://tr.rbxcdn.com/...). Paste link tersebut ke kolom Link Preview.
3
Isi Form & Kirim
Kembali ke form, pilih Gender, Kategori, Rarity, lalu isi Asset ID dan Link Preview. Untuk Uniform, isi nama set + ID/link Shirt & Pants. Klik Kirim — rekomendasi akan masuk ke Discord admin.
